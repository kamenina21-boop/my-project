# 生活管理アプリ

習慣トラッカー、Todoリスト、日記、モチベーション管理、目標管理・振り返りのオールインワンCLIアプリです。

## 機能

- **習慣トラッカー** - 習慣の登録・毎日の達成記録・ストリーク管理・週間進捗グラフ
- **Todoリスト** - タスクの追加・優先度管理・期限設定・完了管理
- **日記** - 毎日の記録・気分トラッキング・振り返りメモ
- **目標管理・振り返り** - 目標の設定・進捗管理・マイルストーン・定期振り返り

## 使い方

```bash
python main.py
```

## 動作要件

- Python 3.7 以上
- 外部ライブラリ不要（標準ライブラリのみ使用）

## データ保存

データは `data/` ディレクトリにJSON形式で保存されます。
